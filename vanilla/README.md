# vanilla

Drop a supported ROM file here, then run `make rip` from the root directory
to extract the game assets:

- Final Fantasy V 1.0 (Japan), CRC32 `C1BC267D`
- Final Fantasy V 1.10 (RPGe), CRC32 `17444605`
- RPGe-compatible patched ROM, CRC32 `C6A5F671` (headerless) or `B39211CF`
  (with its 512-byte copier header)

The patched ROM is extracted using the RPGe asset definitions.
